# LSTM Next Word Prediction

A deep learning project that predicts the next word in a sequence of text using Long Short-Term Memory (LSTM) neural networks.

## Technologies Used
- Python
- TensorFlow 2.15.0
- Keras
- NumPy
- Pandas
- Jupyter Notebook

## Project Goals
- Preprocess and tokenize text data.
- Create sequences for next-word prediction.
- Train an LSTM model using TensorFlow and Keras.
- Predict the next word from a given sequence of words.

## Installation

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```
